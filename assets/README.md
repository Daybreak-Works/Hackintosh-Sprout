## AI provenance and prompt

This artwork was generated with AI under direct human instruction and approval. Approval concerns the visual design; it is not a legal clearance or hardware validation. Generation is nondeterministic, so rerunning a prompt does not reproduce identical bytes.

The generation prompt follows:

```text
Use case: ads-marketing. Generate an original polished GitHub README banner for an independent HP86F3 Hackintosh research project. Single finished full-bleed landscape banner, aspect ratio exactly 3:1, high resolution. Apple Mac campaign-inspired graphic design with exquisite typography and restraint. This is a fresh design, not a screenshot or mockup of a web page. Never add the Apple logo, Android logos, UN1CA text, badges, browser/phone chrome, buttons, URLs, human figures, photographic scenery, mountains, forests, lakes, or any claims of official Apple affiliation. Keep all text within generous safe margins, readable at mobile width. Typeset only these three text lines, precisely spelled: small 'HP86F3-HACKINTOSH'; huge primary title specified below; small 'macOS compatibility research'. Modern neutral sans-serif typography similar in clarity to Apple's web typography. No extra text, no option labels inside the artwork.
Primary title (verbatim): "Sequoia".
Art direction: graphic icon mosaic inspired by the user-provided UN1CA header's large centered title over subtle cropped flat icons, reinterpreted as a refined Mac software banner. Soft luminous pastel gradient in pale apricot, pearl, lavender and faint powder blue. Large low-contrast tone-on-tone Mac-related generic icons arranged as an expansive cropped background pattern: desktop display, command-key loop symbol, mouse, window outline, folder, keyboard, terminal prompt and gear. Crisp flat vector-style symbols, restrained round corners, no Android icons. Central title in very large dark graphite medium-bold sans serif with excellent contrast, surrounded by a calm negative-space zone, no outlines on text. Small project name above, subtitle below. Background motifs are quiet but clearly recognizable. Sophisticated flat branding, soft translucent layered panels only in the far edges. Strong symmetrical composition inspired by a premium software release hero.
```
