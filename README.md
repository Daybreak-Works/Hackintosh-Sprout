# HP86F3-Hackintosh — Tahoe

Future macOS Tahoe compatibility research for the HP All-in-One 22-dd0xxx / HP 86F3.

**Status: DEVELOPMENT NOT STARTED.** This branch currently contains introductory documentation and banner artwork. No Tahoe-specific EFI configuration, installation procedure, hardware test or release has been developed or validated.

## When development will begin

Tahoe development will begin **only after Sequoia reaches its first accepted beta or the Sequoia project is completed**. Sequoia remains the current development priority. Readiness is assessed through the [Sequoia beta acceptance criteria](https://github.com/Vynzaro/HP86F3-Hackintosh/blob/Sequoia/docs/BETA_ACCEPTANCE.md).

The latest evidenced Sequoia test is `26.1.1-alpha.14`, classified as unstable alpha. No beta has been declared. Tahoe has no scheduled release date.

## Planned scope

When the prerequisite is met, this branch will document a separate Tahoe baseline, compatibility investigation, version-specific changes, test evidence and recovery procedures for the HP 86F3. Sequoia results do not establish Tahoe compatibility.

Follow the current work in the [Sequoia README](https://github.com/Vynzaro/HP86F3-Hackintosh/blob/Sequoia/README.md), [version history](https://github.com/Vynzaro/HP86F3-Hackintosh/blob/Sequoia/docs/VERSION_HISTORY.md) and [known issues](https://github.com/Vynzaro/HP86F3-Hackintosh/blob/Sequoia/docs/KNOWN_ISSUES.md).

The project is independent and is not affiliated with or endorsed by Apple or HP. The banner contains no Apple logo or copied operating-system assets.
